Project M 무료 VFX 조사와 적용 계획
기준일 2026년 10월 29일 Asia/Seoul
프로젝트 Unity 6000.3.21f1 / URP 17.3.0 / 정면 직교 카메라의 2.5D 전투
후보 선정과 적용 설계 제안. 최종 아트 확정·다운로드·패키지 임포트·스킬 연결·Unity 재생 및 성능 검증은 수행하지 않음.
공식 무료표기 17개 Unity Store 패키지와 외부 무료 재료·도구를 조사했다. 중복 4건을 합치면 43개 제품군이다. 이 수치는 모두를 도입하거나 모두가 무조건 상업 이용 가능한 완성 VFX라는 뜻이 아니다.

1 추천 방향과 우리 게임의 기준
====================================================================

무료 툰 프리팹을 주력으로 삼고 색·크기·타이밍을 통일한다. Cartoon FX Remaster Free를 타격/폭발 기본으로, Free Slash VFX를 참격 후보로 먼저 비교한다. 대시와 탄 꼬리가 부족할 때만 Trails VFX URP를 보조로 넣고, 마력장/예고는 기존 링과 Kenney CC0 재료로 짧게 보완한다.

우리 게임의 약3등신 3D 주인공, 단순한 KayKit 몬스터, 낮은 채도의 현대도시, 정면 직교 카메라에서는 굵고 짧은 툰 형태가 읽힌다. 픽셀 HUD가 있다고 월드 전투 VFX를 전부 픽셀로 바꾸면 통일감이 깨진다. 외부팩을 많이 섞으면 무료라도 서로 다른 bloom, noise, timing, shader를 맞추는 비용이 커진다.

게임 스타일 판단은 저장된 최신 치비 캐릭터/롱소드 공격 검수 이미지와 도시 이미지, 현재 카메라·재질 설정을 대조한 결과다. 공식 이미지 직접 시각 확인은 CFX/Free Slash/Simple FX의 정지 프리뷰에 한정하며 나머지 후보의 스타일 적합도는 제품 설명과 기술정보 기반의 잠정 판단이다.
물리: 아이보리 중심/옅은 금빛 가장자리. 얇은 초승달과 짧은 속도선. 불필요한 긴 광기둥 제거.
마법: 청록 또는 옅은 보라를 한 계열로 정하고 작은 밝은 코어+짧은 꼬리. 지속 고채도 네온을 화면 전체로 퍼뜨리지 않음.
폭발: 아이보리 섬광→노랑/주황의 큰 덩어리→소량 파편→짧은 회색 연기. 플레이어·적 윤곽이 다시 빨리 보이게 함.
지면과 범위: 마법진의 장식보다 실제 피해범위의 좌우 끝과 높이를 먼저 읽히게 함. 정면 카메라에서는 XZ 링만으로 부족해 양 끝 짧은 기둥/수직 마스크 보완.
적 공격: 아군의 물리/마법 형태와 구별되는 경계/맥동. 적 위험 범위는 색뿐 아니라 모양·예고 애니메이션으로 구분.
낮출 요소: 실사 두꺼운 연기, 오래 남는 전체화면 bloom, 매타 화면왜곡, 코믹 BOOM/POW 글자 기본 노출, 픽셀 팩 무분별 혼합.
시간 시작안: 일반 참격 .10~.25초, 작은 적중 .12~.35초, 대시잔상 .10~.25초, 주폭발 .25~.45초+별도 잔광/연기 .3~.6초. 제작 출발값이며 현재 전투 판정값을 변경하는 규칙은 아님.

현재 환경 팔레트 참고: {'asphalt': '#3B4652', 'navy': '#293D50', 'teal': '#498F8C', 'ivory': '#F1E9D4', 'warm_window': '#E7C781'}

2 먼저 비교할 조합
====================================================================

타격과 폭발
우선: Cartoon FX Remaster Free
대안: Free Stylized Impacts and Explosions URP 또는 SimpleFX
비교 기준: bloom 낮추고 코믹 텍스트 제거한 상태로 도시/주인공과 비교; 충격 때 적 실루엣·범위 읽힘

검기와 근접 참격
우선: Free Slash VFX
대안: 기존 CombatVFX_v1 Crescent/Core와 짧은 파티클
비교 기준: 실제 정면 XY카메라, 좌우/상하 조준, +Z-forward와 원점, 외부팹 왜곡 off, 연속5타 중첩

대시와 마력탄 꼬리
우선: 기존 코어+Trails VFX URP 일부
대안: TrailRenderer+Kenney Particle Pack
비교 기준: 짧은 수명/얇은 폭으로 이동 방향 읽힘; 플레이어 몸과 바닥을 가리지 않음

장판과 예고
우선: 기존 Ring/간단 메시+Kenney CC0
대안: Vefects Shockwaves 또는 Effekseer CC0에서 PNG 베이크
비교 기준: 실제 Box/Sphere의 좌우 범위·높이, 정면 지면에서 경계 가시성, 시작/종료/취소 일치

Vefects Flipbook Lite는 Store판의 무료·Standard EULA를 확인했다. 다만 무료판의 색상 선택/RGBA 마스크/Emission 편집 기능 제한으로 우리 팔레트 통일에는 불리하므로 최종 우선순위는 예비 비교군이다. 일부 개별 조사에서의 상위 A/B 제안보다 기능 제약을 무겁게 반영했다.
가장 적게 섞는 안은 CFX+Free Slash 2팩이다. 실제로 꼬리가 부족한 경우 Trails URP를 추가한다. Magic Effects FREE 한 팩으로 넓게 맞추는 안도 대조할 수 있으나 Unity6·재질 변환은 먼저 검증한다.

3 스킬별 적용 계획
====================================================================

대시
형태: 짧은 발먼지+몸통 뒤 1~2줄+선택 잔상
후보: Trails URP / Kenney Smoke / 기존 DashBurst 재료
현재 구현과 연결: 플레이어 이동은 현재 대시 코드가 담당. sample 내부 전진/높이 제거한 variant, 몸에 붙는 꼬리와 월드먼지 분리

검기
형태: 진행방향의 넓고 얇은 초승달+끝 스파크
후보: Free Slash VFX / 기존 SlashWave
현재 구현과 연결: 실제 SkillProjectile speed15/range5/hitRadius.5/pierce. visual은 이동하지 않고 루트만 따라감. 화면 크기를 hitRadius와 비교

회전베기
형태: 시전자 주변 타원호+짧은 360도 잔상
후보: Free Slash를 회전형 variant로 가공 / 기존 Ring
현재 구현과 연결: 현재 1회 DamageBox=(3.5,2,2), 높이.65. 바닥에 누운 링만 쓰지 않고 몸 앞/뒤를 구분

연속참격
형태: 짧은 5회 호와 작은 적중, 마지막타만 약간 강화
후보: Free Slash 짧은 preset+CFX 작은 hit
현재 구현과 연결: 현재 5회/.08초, 마지막 명목.32초. .95초 sample을 매타 유지하면 과도한 중첩. 스킬취소 시 후속시각도 정지

마력탄
형태: 작은 청록 코어+짧은 tail+적중 폭발
후보: 기존 MagicMissile 코어+Trails/CFX hit
현재 구현과 연결: 현재 투사체 speed12/range8/hitRadius.4/explosionRadius1.5/explodeAtEnd=false. 기획상 목표지점 즉시 범위 공격과 차이 있어 이동방식은 팀에서 정리. VFX가 피해로직을 결정하지 않음

마력장
형태: 뚜렷한 경계+좌우 끝 표시+저밀도 상승입자
후보: 기존 Ring+Kenney, 필요시 Effekseer CC0 베이크
현재 구현과 연결: 현재5틱/.5초/첫틱즉시, 마지막 약2초, Box4×1.5×2. prefab scale4×.1×2를 그대로 상속하면 새 아트가 납작해지므로 단위 root/visual child 필요

연쇄폭발
형태: 각 지점 예고→충격 flash/ring→분리된 잔광
후보: CFX explosion 또는 Free Stylized Impacts URP
현재 구현과 연결: 현재5회/.12초,1.5거리간격,반경1.5,마지막명목.48초. SkillExplosion 회수 .3초보다 긴 연기는 별도 수명으로 분리. 실제 피해 시점에 Detonate 호출

스킬의 수치/개수/틱/속도는 조사 시점의 직렬화 값과 코드를 설명한다. 이 보고서가 밸런스를 확정하거나 바꾼 것은 아니다. 모든 SkillData의 CastDuration=.4초이며 연쇄 마지막 생성의 명목시간=.48초와 차이가 있어 취소·시전 종료 시 연출을 어떻게 처리할지 팀이 일치시켜야 한다.

4 기존 CombatVFX 샘플의 처리
====================================================================

보존: 독립 비교 기준으로 보존. Crescent/Ring/Core/Shard/Ribbon과 색의 방향은 재사용 가치가 있음.
가공: 원본샘플을 스킬 담당자에게 최종 에셋으로 바로 넘기기 전에 Play 어댑터, 내부 이동/높이 제거, 종료/풀링, 단위크기 처리한 runtime variant 필요.
연결 시 확인할 점: SetActive만으로 Play되지 않음 / 투사체 root 이동과 sample 내부 Visual_Travel 이동이 중복 / sample 높이 .82~1.1m를 이미 어깨/적중 위치에 더하면 이중 높이 / sample Explosion1.55초가 기존 SkillExplosion .3초에 회수되어 잘림 / 완료는 Completed 이벤트일 뿐 자동 반환/파괴 없음 / 샘플의 수동 ParticleSystem.Simulate와 런타임 자동시뮬레이션을 함께 쓰지 않음
샘플 구성값: DashBurst .60초, SlashWave .95초, MagicMissile1.05초, Explosion1.55초. ParticleSystem MaxParticles 합계는 각각14/12/16/61. 이는 살아 있는 입자 수·드로콜·GPU실측값이 아니다.
현재 6개 스킬은 이미 판정과 프리팹 연결을 갖고 있다. 2026-10-19 vfx-plan.txt의 TestLogSkill만 존재한다는 설명은 오래되었다. 기존 문서는 수정하지 않고 이 보고서에 현재 상태를 기록했다.

5 직접 제작할 경우의 현실적인 방식
====================================================================

제작 방향: 직접 만든다면 완성형 이미지/3D 모델 하나를 생성하기보다 이미 있는 메시와 공용 texture로 작은 블록을 조합. Shuriken ParticleSystem+TrailRenderer+필요시 공용 ShaderGraph 1개. 복잡한 VFXGraph 신규도입은 초기 범위에서 제외.

공용 블록
  1. 초승달 메시와 UV마스크 1종: 검기/회전/연속참격 공유
  2. 별/스파크마스크: 모든 적중 공유
  3. 작은 코어+짧은 trail: 마력탄과 적 원거리 공격 공유
  4. 경계링/좌우끝: 장판/폭발예고 공유
  5. 불꽃 flipbook+파편+연기: 작은/큰폭발 공유

작업 순서
  1. 실제 카메라 스케일에서 흑백 실루엣을 먼저 비교
  2. 기존 메시 또는 Blender/VFXMeshLab으로 저면수 호·링·파편만 제작
  3. Kenney/다른 명확한 무료 라이선스 마스크를 URP/Particles/Unlit에 적용
  4. 방출/알파/크기/색 곡선으로 예고·타격·잔광 타이밍 조정
  5. 복잡한 불/연기는 Effekseer CC0 샘플→정면 PNG시퀀스→플립북; 새 런타임 의존성을 넣는 경로는 별도 검토
  6. 8~16프레임 또는4×4 atlas를 시작점으로 테스트; 작은효과 .1초대는 프레임을 빠르게 재생해 길게 늘어지지 않게 함
  7. 공용 tint/intensity/radius/duration을 노출하고 9개 전달 preset으로 묶음

AI의 역할: AI는 구조 코드·파라미터 초안·단일 마스크/콘셉트 보조에 한정하는 것이 현실적. 연속 이미지 프레임의 형태/알파 일관성, 스킬 판정 정렬, 잔광과 풀링은 별도 작업. Meshy가 만든 고정 메시나 생성 영상이 바로 Unity VFX가 되지는 않는다. 무료 에셋 조건에서 유료 생성 크레딧을 무상이라고 계산하지 않는다.

무료 도구: Unity 기본 ParticleSystem/TrailRenderer, Blender, Krita, Effekseer, MIT VFXMeshLab. 웹 CrunchyVFX는 픽셀/UI보조 후보. JangaFX 무료 VDB는 실사 베이크 부담으로 현재 비추천.

예상 공수: 무료팩 A/B/임포트점검 .5~1인일+색/타이밍/통합1~2인일+게임QA .5~1인일, 총2~4인일 수준의 초기 견적. 기존샘플 완성화+부족한장판/회전/예고는 초안2~4인일+마감/QA2~3인일. 신규flipbook·셰이더 전체제작은 초안3~5인일, 학습포함1~2주 가능. 담당자 경험/플랫폼/완성도에 따라 크게 달라지는 추정이며 실제 작업시간 측정 아님.

텍스처의 시트 크기와 재생 길이를 구분한다. 예를 들어 16프레임을16fps로 재생하면1초가 되어 .1초대 참격에는 길다. 프레임 수를 줄이거나 재생 속도를 조절하고 마지막 프레임의 알파를 확인한다. 플립북이 예쁘다는 이유로 타격 프레임을 지연시키지 않는다.

6 팀원에게 전달할 규격과 일정
====================================================================

전달할 9개 variant: VFX_Dash / VFX_SlashProjectile / VFX_Spin / VFX_FlurryHit / VFX_MagicProjectile / VFX_MagicImpact / VFX_MagicField / VFX_ChainWarning / VFX_Explosion

좌표: unit scale root, 원점=실제 적중점 또는 지면 기준점. 로컬+Z forward,아트오프셋은 visual child에서. gameplay XY조준 dir은 현재 LookRotation 사용.

수명: Configure(position,direction,tint,scale,duration)→Play→Impact/Tick(optional)→StopEmitting→모든입자/트레일/메시잔광완료→1회 Release. 이동/충돌/데미지는 기존 스킬코드 소유.

풀링: 현재 SkillSpawner.UsePool=false지만 범용 PoolManager가 있으므로 새 풀 시스템을 따로 만들 필요 작음. 전용 key와prefab등록/PreparePool,비활성Rent→설정→Play,Stop/Clear/Tail완료를 함께 처리해야 하며 bool만 켜면 완료가 아님.

첨부 정보: 프리팹마다 출처/라이선스파일/원본버전/URP의존성/정면프리뷰/축·피벗/주동작·잔광수명/scale기준/loop/노출파라미터/풀반납조건을 기록.
