UI는 게임플레이 코드를 직접 참조하지 않는다. 팀원도 UI 프리팹 내부를 몰라도 된다.

5회의에서 정할 것

  1. 메뉴 열 때 시간 정지 — 기획서 기본안은 스킬 창 정지. 현재 스킬 창·인벤토리·지도·일시정지 모두 정지로 구현. 인벤/지도도 정지할지?
  2. 입력 분담 — Q/E/R · 1~4는 플레이어 담당이 입력 처리, UI는 이벤트만 받음. UI 키는 K 스킬 · I 인벤토리 · Tab/M 지도 · ESC 일시정지. 공용 InputSystem_Actions는 수정하지 않음.
  3. 세이브 범위 — 지도 발견 상태도 스테이지 입장 저장에 포함할지 (사망 시 초기화 규칙과 같이).
  4. 카메라 픽셀 기준 — UI는 640×360 × 정수 3배(1920×1080). 월드는 3D 로우폴리라 Pixel Perfect Camera는 필수 아님.
  5. 공지 — TMP 기본 리소스는 02.parkhansol_/ThirdParty/TextMesh Pro에 있음. TMP Essentials 재설치 금지.
  6. 아트 — 스킬·아이템 아이콘, 초상화 교체 담당과 일정.
