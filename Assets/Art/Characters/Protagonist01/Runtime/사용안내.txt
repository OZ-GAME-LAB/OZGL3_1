주인공 01 — Unity 사용 안내

1. Protagonist01_Playground.unity를 열고 Play를 누르면 바로 조작할 수 있습니다.
   A/D: 이동(달리기), Ctrl+A/D: 걷기, Space: 점프, Shift: 대시,
   마우스 좌클릭: 커서 방향으로 주먹 공격. 오른쪽 큐브는 피해 확인용 더미입니다.

2. 게임에 넣을 때는 Protagonist01_Player.prefab을 사용합니다.
   기존 플레이어의 체력·스탯·스킬·주먹 판정과 같은 로직을 가진 새 프리팹이며,
   입력 참조와 Ground 레이어(6), Enemy 레이어(7)가 연결되어 있습니다.
   Animator는 플레이어 루트에 있고 실제 이동·점프는 Rigidbody가 담당합니다.
   Apply Root Motion은 끕니다. 장면에 MainCamera 태그의 카메라와 Ground 지면이 필요합니다.
   기존 MainScene과 기존 Player.prefab은 자동 교체하지 않았습니다.

3. 외형/애니메이션만 사용할 때는 Protagonist01_Visual.prefab을 사용합니다.
   Humanoid Avatar와 URP Unlit 머티리얼이 연결되어 있습니다.
   Animator의 Walk=true, Speed=2.2에서 걷기, Speed=5에서 달리기입니다.
   Idle은 기본 상태입니다. 주먹은 Attacking=true와 Attack 트리거로 재생하고
   Attacking=false로 종료합니다. 단독 Visual 사용 시 AttackSpeed 기본값은 1입니다.
   실제 Player에서는 ProtagonistAnimationDriver가 Punch 클립 길이/공격 지속시간으로
   AttackSpeed를 설정합니다. 민첩의 공격 속도 증가도 반영됩니다.

4. 점프 원본 JumpFull 외에 JumpTakeoff·AirApex·Land 클립을 나눴습니다.
   실제 플레이어는 도약 → 공중 → 착지 상태를 사용합니다. 점프의 루트 높이 궤적은
   물리 점프에 중복 적용하지 않습니다. Dash·Hit·Dead는 기존 프로젝트 클립을 재사용합니다.
   Skill 트리거는 호환용으로만 연결되어 있고 새 무기 스킬 모션은 이번 생성 범위가 아닙니다.

5. 무기는 별도 메시/프리팹으로 제작해 오른손의 WeaponSocket에 붙이면 됩니다.
   보조 손에는 WeaponSocket_Left가 있습니다. 소켓 로컬 위치·회전은 무기 그립에 맞춰 조정합니다.
   무기 전용 리그 없이 공통 캐릭터 리그와 무기별 공격/대기 모션을 공유할 수 있습니다.
   구매 잠금·자동 장착·무기별 스킬 조건은 별도 게임 상태로 처리해야 합니다.

6. Meshy 자동 리그는 24개 뼈를 사용하며 손가락별 뼈는 없습니다.
   정밀한 손가락 그립이나 표정은 별도의 후속 리깅 작업 대상입니다.
   재생성은 Tools > Project M > Build Protagonist 01 메뉴에서 가능합니다.
   검증 기록과 생성 비용(총 14크레딧)은 ArtSources/Characters/Protagonist01/v002-rigged에 있습니다.
