레벨 조립 (이하 경로는 이 폴더 기준)
Prefabs/Blocks/에서 Tutorial_Block, Stage01_Block, Stage01_ExpandedStreet_Block, Stage01_ExpandedBoss_Block을 배치하거나 복제해서 사용하세요. 개별 부품은 Prefabs/Modules/(기본 건물·도로·다리·계단·옥상), Prefabs/Expansion/(확장 건물·구조물·도로·소품), Prefabs/Props/(가로등·나무·자판기·벤치·위성접시·물약 등)에 있습니다.

진행 축은 X, 높이는 Y이며 카메라는 -Z 쪽에서 봅니다. 도로·보도·다리는 SnapLeft / SnapRight / WalkableSurface, 건물은 RoofSurface / RoofLeft / RoofRight / GroundFront를 기준으로 연결합니다. 보행면은 Ground 레이어(6)의 BoxCollider를 사용합니다. 플레이어의 Ground Check 마스크에 이 레이어를 포함하세요.

Tutorial_Block의 PlayerSpawn / TutorialMonsterAnchor / TutorialGateAnchor / Stage01Exit와 Stage01_Block의 PlayerSpawn / NormalGate_1~3 / BossArenaAnchor / BossGateAnchor는 위치 표식입니다. 몬스터 스폰, 게이트 작동 및 보스 진행은 게임 코드에서 연결합니다. 사다리는 ClimbBottom / ClimbTop 위치를 제공하며 이동 동작은 별도로 연결합니다. 기본 건물 4종은 LODGroup이 있고 환경 메시는 Materials/Urban_SharedPalette.mat와 Urban_VertexColor.shader를 공유합니다.

무기·소품 연결
Prefabs/Weapons/Sword.prefab과 Staff.prefab에는 SocketWeapon이 있습니다. HandSocketEquipment를 구성한 플레이어에서 Equip(socketWeaponPrefab)으로 장착하고 Unequip()으로 해제합니다. WeaponSocket(오른손)과 WeaponSocket_Left(왼손)를 준비하세요. 진행 방향에 따라 가까운 손으로 옮기며 NearHandSocket과 UsesLeftHand로 현재 손을 확인할 수 있습니다. Staff.prefab에는 수정 끝 표식 EffectTip이 있습니다.

기본 무기 프리팹의 Animation Override와 Basic Attack Clip은 비어 있습니다. 기본 공격 변경, 실제 검 타격·마력탄 생성 또는 구매 처리는 사용하는 캐릭터에 맞춰 연결하세요. 바로 시전해 볼 수 있는 치비 예시는 Assets/Art/Characters/Protagonist01/AnimationStudies/StaffTipBolt20261102/Player_Chibi_StaffTipBolt.prefab입니다. 빈 씬에 놓고 Play한 뒤 인스턴스의 Animator > Parameters에서 Cast를 누릅니다.

프리뷰 입력을 별도로 구성하는 경우
UrbanKitPreviewControls에 검, 지팡이, 물약 프리팹을 지정하고 같은 플레이어 오브젝트에 HandSocketEquipment와 ProtagonistActionAnimator를 준비하세요. 호환 컨트롤러와 액션 상태가 있는 프리뷰용 플레이어에서 F1 / F2 / F3은 검 / 지팡이 / 맨손, 5 / 6 / 7 / 8은 마시기 / 던지기 / 상호작용 / 줍기입니다. 이동·점프·기본 공격은 이 프리뷰 스크립트가 처리하지 않습니다.

마시기·던지기·상호작용·줍기는 ProtagonistActionAnimator의 TryDrink / TryThrow / TryInteract / TryPickup으로 요청합니다. 반환값 true는 동작 수락을 뜻합니다. 아이템 소비나 투사체 생성은 onCommit에서 한 번 처리하고, 정상 종료는 onCompleted, 취소 시 정리는 Cancelled에서 처리하세요. 샘플의 물약 투척은 시각 표현이며 실제 피해나 상태이상 효과가 없습니다.
