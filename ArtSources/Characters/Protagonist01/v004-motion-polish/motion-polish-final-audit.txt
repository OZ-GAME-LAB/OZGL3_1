  오른 distal pad48점의 X -2.16~-.73cm/Y3.54~6.33cm, 왼34점의 X .97~2.21cm/Y3.29~5.41cm.

C0/C1 판단 정정
- 초기 1cycle의 끝점 외삽/JSON leftLoopVelocityGap을 실제 C1 불연속처럼 읽은 판단은 정정한다.
- 해당 JSON 지표는 인접 두 유한 차분 속도의 차이이며, 자연스러운 가속도×dt도 포함한다.
- 최종 Idle/Walk/Run 2cycle에서 동일 위상 위치 차이가 1µm 미만이고 endpoint curve tangents를 같게 저장한다.
  따라서 큰 위치 점프나 q 부호 flip의 증거는 없다.
- Walk 왼발 접촉 전 감속 약25m/s²는 남지만 연속 궤적이다. Run 비행을 접지 실패로 간주하지 않았다.
- XZ in-place clip의 뒤로 움직이는 stance 발 속도를 실제 게임 foot-slip으로 부르면 안 된다.
  이후 실제 root 이동속도를 더한 상태에서 ground-relative slip을 측정해야 한다.

적용 범위와 남는 제약
- 새 .anim은 이 24-bone hierarchy를 직접 구동하는 Generic curve다. Humanoid retarget용 원본 Sources FBX는 별도다.
- Jump/Plunge에는 baked hip Y가 있다. 실제 게임 physics/root 이동과 중복하면 안 된다.
- 이 검수는 시각 동작/접지/루프/손 모델 검사이며 hitbox, damage, action cancel, 게임 controller 통합 검사가 아니다.
- finite clip의 끝→첫 장면을 강제 loop로 보정해 실제 동작을 바꾸지 않았다. 특히 Plunge는 공중 시작/지상 종료다.
- 60Hz bake는 원본30Hz source를 보간/보정한 저장 형식이다. 원본의 새 촬영 정보가 60Hz였다는 의미는 아니다.
- GIF는 실제 저장 clip의 1x 프레임이며 VFX/소품 샘플은 별도 preview 동작이다.

최종 증거 확인
- 14개 저장 clip의 frame manifest와 실제 1039개 PNG 수가 모두 일치했다.
- 최종 sample에서 최소 meshY는 Walk +.002162m이며, 다른 동작도 바닥 아래로 관통하지 않았다.
- Throw의 저장 Grip_R curve를 직접 읽어 시작75/최저15/종료100을 확인했다.
  source notes의 단일 hands=75 표기에 의존하지 않았다. 검/스태프/포션은75, 기본 주먹은100이다.
- 새 손 mesh 보고서의 4 shape frame은 fist260도/weapon160도이며, Hands8장이 모두 존재한다.
- 현재 검토한 sideview 자료에서 추가 작업을 막는 중대한 시각 결함은 확인하지 못했다.
  이는 고정 리그/고정 카메라의 동작 검토 결과이며, 임의 카메라/모든 retarget/실제 게임 통합까지 승인한 것은 아니다.
