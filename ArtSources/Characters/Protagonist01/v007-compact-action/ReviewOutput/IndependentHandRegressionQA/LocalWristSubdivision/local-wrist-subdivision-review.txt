v007 국소 손목 세분 후 비무기 손 회귀 검수
검수일: 2026-10-21

결론과 범위
보존한 이전 원본 PNG 62개와 새 원본 PNG의 같은 시점을 실제로 비교했다. 이 표본의 보이는 오른손에서, 이번 국소 세분으로 새로 생긴 손목 관통·표면 구멍·손가락 분리·긴 돌출이나 심한 납작해짐은 확인하지 못했다. 대기/걷기/달리기의 닫힌 주먹, 투척/줍기 중 손의 열림과 닫힘도 유지된다.
손과 소매 가장자리 및 국소 음영에는 작은 변화가 있다. 이전과 바이트/픽셀 단위로 모두 동일하다는 판정은 하지 않는다. 이 검수는 새 회귀 결함의 확인에 한정하며, 전체 애니메이션의 자연스러움이나 가려진 접촉면·무기 그립의 합격 판정은 아니다. 원본 vertex/UV/morph 보존의 수치 증명도 다른 담당자의 범위다.

기준 자료
- QAHistory/before-local-wrist-subdivision/Frames에 보존한 62개 원본 PNG와 같은 폴더의 review-report.json을 사용했다.
- 이전 GIF를 기준으로 삼았던 앞선 ReferenceRebuild 검수와 달리, 이번에는 원본 PNG와 원본 PNG를 직접 비교했다. 색상 팔레트 양자화나 추정 프레임 대응을 사용하지 않았다.
- local-topology 로그의 CHIBI_V007_CAPTURE_SUCCESS와 return code 0을 확인한 뒤 새 PNG를 읽었다.
- 동일 카메라/구도/크기를 확인했다. 원본 720x720, cameraPosition (1.05,2.78,-10), target (0,.78,0), orthographicSize 1.05다.

동작별 관찰
- Idle/Walk: 주먹의 외곽과 소매 연결은 같은 구조다. 국소 음영 차이 외에 손이 벌어지거나 팔에서 떨어지는 변화는 보이지 않는다.
- Run: 앞쪽 주먹의 엄지와 손등 윤곽이 유지된다. 몸 뒤의 가림은 전후 동일하며, 가린 안쪽 면을 새로 확인한 것으로 취급하지 않는다.
- Potion: 병을 올리고 내리는 손의 형태가 유지된다. 마시는 유지 구간은 손 안쪽이 소품/소매에 가려져 있으므로 내부 접촉면의 완전 검증은 불가능하다. 보이는 부분에 새 손 붕괴나 병과의 새 분리는 보이지 않는다.
- Throw: 머리 뒤에서 감싸는 포즈, 방출 뒤 빈손, 복귀 주먹이 유지된다. 앞선 엄지 교정에서 넓어진 외곽을 이번 세분이 다시 크게 변형한 모습은 보이지 않는다.
- Pickup: 내려간 열린 손과 닫히는 손의 구분, 신발과의 실루엣 구분이 유지된다. 표본에 새 손목 가시나 손가락 파손은 보이지 않는다.

수치 교차 확인
- 전체 421프레임에서 report의 hips/head/leftHand/rightHand/leftElbow/rightElbow/gripL/gripR 값의 최대 차이는 모두 0이다. 기록되지 않은 모든 bone 회전이 같다는 주장은 하지 않는다.
- 62개 원본 중 54개는 RGB 차이가 있고, 8개는 RGB 배열이 같다. 각 동작 표본의 최대 변화 pixel 수는 Idle 118, Walk 91, Run 88, Potion 167, Throw 108, Pickup 100이다.
- 이 작은 차이 수를 자연스러움/물리 접촉의 점수나 합격 임계값으로 사용하지 않았다. 해당 프레임의 실제 이미지를 확인하기 위한 위치 선정에만 사용했다.
