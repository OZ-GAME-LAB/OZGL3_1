1스테이지 근접형 한 종 샘플 검수
2026-10-26 Asia/Seoul

결과
청록 망토 해골 근접병 한 종의 모델·스킨·원래 리그와 네 클립을 제공한다.
한 종의 외형과 동작을 피드백하기 위한 샘플로 제시 가능하다.
기획에 종족과 무기가 확정되어 있지는 않으므로 해골/한손 칼은 이번 제안이다.
기존 주인공·환경·게임 코드·Animator 전환 로직·VFX는 편집하지 않았다.

배율과 리그 사용
대기 몸체 높이는1.15m, 참고 주인공 메시 높이는 약1.166m.
주인공은 읽기 전용 복사에서 평가한 정지 메시로 비교 장면에만 넣었다.
다른 캐릭터에 모션을 옮기지 않고 KayKit의 원래 체형/스키닝/리그를 유지했다.
관절 궤적을 새로 합성하지 않았다. 편집은 균일 배율, 색상, 무기 장착 축,
클립 전체의 일정한 바닥 높이 오프셋과 가져오기/내보내기 정리에 한정했다.

1 주요 자세 검수
실제 스키닝된 메시를 측면·정면·반대쪽·후면에서 확인했다.
칼을 세우는 준비, 전방으로 떨어지는 칼, 회수 자세가 측면에서 구별된다.
파지는 원래 handslot.r을 사용한다. 시각 검수에서 손과 손잡이 분리,
뚜렷한 팔꿈치 역꺾임, 손목 뒤집힘, 어깨나 망토의 큰 붕괴는 발견하지 못했다.
주인공과 실루엣·단위 크기를 비교했다. 다른 적의 체형은 제작하지 않았다.

2 전체 동작 검수
Unity 측면의 Idle129/Move25/Attack33/Hit21개 프레임과 공격의 네 방향
전 프레임을 독립 검수했다. 나머지 클립의 보조 방향 주요 자세도 확인했다.
PNG는 시작과 끝 프레임을 모두 보존한다. GIF는 중복 끝 프레임을 제외하고
30fps 기준 시간을 GIF의0.01초 단위에 분배해 원속도와0.5배속을 제공한다.
정면과 반대쪽에서 팔/몸통 연결과 무기 접촉을 함께 확인했다.
순간 자세 튐은 발견하지 못했다. 달리기는 발끝 지지 시간이 짧고 탄성이 있는
원본 스타일이다. 수평 제자리 클립이므로 최종 게임 이동 속도와 보폭의 일치는
인게임 검수가 필요하다. 발 고정 IK나 지형 대응을 구현했다고 주장하지 않는다.

3 최종 파일 검수
Blender 저장 파일을 별도 프로세스에서 다시 열어 렌더했다.
Unity6000.3.21f1의 격리 프로젝트에서 Generic으로 가져온 뒤 독립.anim과
프리팹을 저장/재로드하고 실제 SkinnedMeshRenderer를 GPU로 렌더했다.
모션 압축/리타게팅을 사용하지 않았다. 원본과 Unity 클립 길이가 일치한다.
Idle/Move 반복과 Idle→Move, Move→Attack, Attack→Idle, Hit→Idle 연결을
검수용 Playables의0.12초 블렌드로 확인했다. 실제 Animator 전환 설정은 아니다.
직접 전환의 끝/시작 자세도 따로 제공하여 블렌드가 차이를 감추지 않도록 했다.
발 침하를 가리지 않도록 Unity 검수 장면의 불투명 바닥은Y-0.05m에 두고,
옆의 주황 표시를 의도한 바닥Y0으로 삼았다. 이는 렌더 검수 장면의 설정이다.
수치 검사와 파일 해시는 일치/누락 확인용이며 시각적 완성도 판정을 대신하지 않는다.

발견한 문제와 수정
무기 길이 축이 손 슬롯 축과 달라 칼이 옆으로 누웠다.
  무기만 고정 X-90도로 회전해 +Z 길이 축을 슬롯+Y에 맞췄다.
  손목이나 팔꿈치 포즈를 왜곡하여 맞추지 않았다.
원본 달리기 발끝이 바닥 아래 약3.2cm에 내려갔다.
  Move의 원래 root 수직 채널 전체에 일정한+0.032263592m를 더했다.
  Attack은 같은 방식으로+0.005913736m를 보정했다. 상대 관절 키/바운스는 유지했다.
무기 FBX 가져오기가 장면 FPS를24로 바꿔 출력이 느려졌다.
  원래30fps를 복원하고 Unity 실제 길이를 원본 초 단위와 대조했다.
기존 원본 Idle 이름과 Idle_Combat 이름 변경이 충돌했다.
  선택하지 않은 원본 액션을 먼저 정리하여 정확한 Idle_Combat을 사용했다.
Unity의 한 에디터 업데이트 안에서 여러 프레임을 캡처할 때 스킨이 캐시됐다.
  검수 복제본에 매 렌더 스킨 행렬 재계산을 설정했고 실제 메시 움직임을 재검수했다.
Unity BakeMesh 스케일 계산 때문에 초기 검수 카메라 범위가 잘못 잡혔다.
  검수 계산만 바로잡았다. 이를 이유로 원본 모션을 변형하지 않았다.

사용과 미확인 범위
프리팹 Animator는 활성화되어 있고 Generic Avatar가 있다. Controller는 비어 있고
Apply Root Motion은 꺼져 있다. 원본 모델 정면은+Z이며, 측면 게임에서+X를 보려면
클립 루트 밖의 부모를Y90도로 회전한다. 클립에 쓰인 계층 이름은 유지한다.
본게임 AI, 피격 판정, 공격 이벤트, 벽/경사/플랫폼, 실제 이동 속도, 인게임 전환과
최종 라이팅/포스트프로세싱 조합은 연결·검수하지 않았다. 별도 Unity 검수 프로젝트에서
확인한 결과이며 실제 기존 플레이 장면을 바꿔 테스트한 결과라고 주장하지 않는다.
실제 플레이 테스트 후 보폭·전환시간 조정이 필요할 수 있다.
준비의 크기나 무게감을 더 바꾸려면 제작자의 SOURCE 제어 리그를 확보해
애니메이터가 자세/발 IK/접촉을 편집하는 방식을 권한다. 반복 코드 궤적 생성은 대안이 아니다.
