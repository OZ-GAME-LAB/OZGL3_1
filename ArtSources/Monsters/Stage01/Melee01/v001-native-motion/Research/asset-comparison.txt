이번 제작의 선택
Kay Lousberg의 공식 GitHub 저장소 KayKit Character Pack Skeletons 1.0의 Skeleton_Minion.glb를 사용한다. 같은 파일에 포함된 원래 스킨·리그·95개 액션 중 네 개를 선택한다. 종족과 무기는 역할명에서 확정된 기획 사실이 아니라 이번 검수 샘플의 아트 제안이다. 다른 체형에 모션을 옮기지 않고 원래 모델과 원래 리그·모션을 함께 사용한다.

영어 납품 클립 이름 / 실제 원본 액션
Idle / Idle_Combat
Move / Running_A
Attack / 1H_Melee_Attack_Chop
Hit / Hit_A

원본 GLB를 직접 읽어 위 액션의 존재를 확인했다. 포함된 95개 액션에는 정적 자세와 추가 동작도 있으므로 95개를 모두 필요한 게임 동작이나 검수 완료 모션으로 세지 않는다. 전체 이름은 source-provenance.json에 기록한다. 점프·회전·사망·등장은 이번 샘플에 자동 추가하지 않는다. 주인공의 레그돌 사망 방식을 적용하지 않는다.

Blender는 GLB의 실제 스킨·뼈·베이크 모션을 가져와 편집용 .blend로 저장하고, 클립 선택·이름 변경·내보내기·렌더·검증에 자동화를 사용한다. 코드로 새로운 관절 궤적을 합성하지 않는다. 납품 .blend는 가져온 데이터로 만든 편집용 파일이며, 제작자가 판매하는 원래 .blend 원본 또는 원래 제어 리그를 확보했다는 뜻이 아니다. 원본 GLB/FBX·텍스처·라이선스를 SourceAssets에 보존한다.

품질과 편집 한계
네이티브 모션을 사용해도 실루엣·준비 시간·체중 이동·발 미끄러짐·어깨와 팔꿈치 변형·파지의 시각 검수는 별도다. 해시 일치와 액션 이름 존재는 동작 품질의 증거를 대체하지 않는다. 실제 검수 내용과 미확인 항목은 QA 및 Review 결과를 따른다. 제자리 이동 클립의 발은 가상의 지면에 대해 뒤로 움직이는 것이 정상이며, 실제 게임 이동 속도와 보폭·주기를 맞춰야 한다. 검수용 스크립트가 기존 인게임 이동 코드를 수정하는 근거가 되지는 않는다.

원본 모션으로도 목표에 맞는 공격 판독성·파지·접지를 확보하지 못하면 같은 방식의 반복 생성을 중단한다. 다음 단계는 KayKit 원래 SOURCE 제어 리그 구입 후 애니메이터가 네 개 클립을 수작업으로 수정하거나, 정해진 2.5D 카메라·주인공 배율·원래 스킨을 제공해 외주로 수정하는 것이다. 외주는 사전·타격·회수 주요 자세와 양 측면 전체 동작, 저장 후 재열기 및 Unity 임포트 검수까지 계약 범위에 넣는다. 외주 견적은 이번 조사에서 받지 않았으며 임의 가격을 제시하지 않는다. 이 샘플에는 AI 영상 생성 또는 AI 모션 생성·유료 자동리깅을 사용하지 않았다.
