빠르게 검토하기
index.html: 번호 검색, 기존/신규·환경/아이템/조립 필터, 측면·입체 전환, 확대 보기.

전체모델링목록.txt: 실제 경로·역할·크기·삼각형 수가 포함된 전체 목록.
catalog.json: 고정 ID와 파일 연결의 기준. 이름을 바꿔도 ID를 유지하고 삭제된 ID를 재사용하지 않는다.

Renders/: 실제 Unity 재질을 사용한 측면·입체 렌더.
ContactSheets/: 기존/신규를 나눈 번호별 한눈에 보기.

검토 근거와 제작 선택
planning/Project_M_상세기획서.docx v0.5의 3·5·7장 및 Project_M_기획데이터.txt를 검토했다.
서울 길거리→상가 내부 또는 외부 계단→낮은 옥상→높은 옥상, 지상·상층 일반 게이트 3개,
선택 아이템 곁길과 재합류, 별도 지도 노드인 높은 옥상 보스를 기준으로 확장했다.
특정 점포 종류와 확장 모델 목록은 이 요구를 구체화한 제작안이며 기획서의 확정 에셋 목록은 아니다.
기존 3m 계단과 4m 낮은 옥상의 차이를 보완하기 위해 4m 상승 계단을 추가했다.
현재 UrbanModuleBuilder/UrbanPropBuilder 코드의 어두운 청회색 팔레트와 Urban_SharedPalette 재질을 사용한다.
environment-plan.json의 초기 밝은 팔레트를 기준으로 새 모델을 만들지 않았다.
실제 브랜드·로고·외부 이미지·텍스처 없이 기하학적 간판과 면 단위 색으로 직접 제작했다.
신규 Meshy 요청이나 유료 생성 크레딧 사용은 없다. 교체 전 Meshy 원본의 출처는 기존 기록을 따른다.
현재 가로등·가로수·자판기·실외기·위성접시는 Stage01SimplifiedProps.cs에서 직접 제작한 메시다.
교체 전 GatePylon FBX는 ArtSources/Stage01Kit/LegacyMeshySources/에 원본 기록용으로 보관하며 활성 모델이 아니다.

배치 기준과 사용 범위
미터 단위, X 진행·Y 높이·카메라 -Z, 기본 플레이 평면 Z=0.
고체 건물 5종은 4/8/12m 옥상 앵커와 LOD0/LOD1을 제공한다.
신규 건물의 주차 베이와 전면 진열은 외관이다. 주차 건물 몸체는 하나의 고체 충돌이므로 내부 통과용으로 쓰지 않는다.
상가 내부 단면 S1-037은 Z=0의 열린 바닥 통로를 제공한다. 부분 천장의 RoofSurface는 (0,4,1.75)로 후면에 있다.
이 부분 천장을 Z=0을 가로지르는 완전한 옥상으로 간주하지 않는다.
계단은 0.25m 상승 16단, 수평 길이 8m다. Entry(-4,0,0)와 Exit(4,4,0)를 연결한다.
발판·도로·바닥에는 Ground 충돌을 사용한다. 삭제한 게이트 받침과 안테나는 조립 블록·씬·재생성 코드에서도 제거했다.
장식 소품은 플레이 레인에 장애물 충돌을 만들지 않는다. 배치할 때 Z 후면을 활용한다.
일반 필드 조립 블록에는 NormalGate_1/2/3, 보스 조립 블록에는 BossGateAnchor와 BossArenaAnchor가 있다.
이들은 위치 앵커와 아트 시안이다. 게이트 봉쇄·몬스터 출현·보상·지도 이동·아이템 파밍 기능은 연결하지 않았다.
사다리는 기존 외형과 앵커를 사용하며 오르기 기능을 추가하지 않았다.
계단 오르기·점프·하강·아이템 접근성은 실제 플레이어 컨트롤러와 카메라를 적용한 뒤 플레이 검증이 필요하다.
정적 형상/앵커 검사는 완료 조건에 포함하지만 완성된 플레이 가능 레벨 또는 기기 성능 측정으로 해석하지 않는다.

수정 대상 모델의 기존 GUID를 유지한다. 위성접시는 기존 GatePylon 프리팹·메시의 GUID를 유지하며 이름을 변경했다.
기존 블록과 씬의 프리팹 참조는 수정된 메시를 따라간다. MainScene의 게임 로직은 변경하지 않는다.
번호는 catalog.json에서 관리한다. 모델 이름이 바뀌거나 삭제되어도 다른 모델의 번호를 당기지 않는다.
