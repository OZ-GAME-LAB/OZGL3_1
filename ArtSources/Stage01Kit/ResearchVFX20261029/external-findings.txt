Project M 무료 VFX 외부 배포처 정밀 조사
기준일 2026-10-29 / Asia/Seoul
환경 Unity 6000.3.21f1, URP 17.3.0, 치비 로우폴리 3D + 현대 도시 + 2.5D 횡스크롤 액션

결론
가장 먼저 화면에서 비교할 외부 후보는 Vefects Free - URP Flipbook VFX Bundle Lite의 Unity Asset Store판이다. Unity 6 URP 지원과 무료/표준 EULA가 공식 페이지에 같이 확인된다. Kenney Particle Pack은 완성 연출의 대체재가 아니라 적은 수정으로 색·모양·수명을 통일할 기초 재료로 좋다. 폭발을 PNG로 보충할 경우 CraftPix의 비픽셀 벡터 Explosion 팩을 비교할 만하다. Effekseer는 수백 CC0 샘플을 재편집하고 플립북으로 베이크할 수 있는 폭넓은 대안이다.

우리 게임에서는 무료 팩 여러 개를 원형 그대로 섞는 방식을 피한다. 치비 캐릭터의 큼직한 면과 얼굴을 읽을 수 있게 흰 중심 섬광, 아이보리 물리 참격, 청록/보라 마력, 노랑→주황 폭발을 공통 규칙으로 묶는다. 효과마다 크기·밝기·지속시간을 조절하는 작업은 어느 무료 팩을 써도 필요하다. '무료 = 완성 전투에 즉시 연결 가능'은 아니다.

조사 범위와 검증 수준
22개 제품군을 기록했으며, 같은 팩의 itch/OGA/Store 중복본은 별도 상품 수로 부풀리지 않았다. Kenney, OpenGameArt, itch.io, CraftPix, GameDev Market, Effekseer, GitHub 제작자, JangaFX, Colorosse, Vefects, Eric VFX, BOOTH, GameArt2D, ArtStation, Godot Shaders 및 검증되지 않은 OpenGameVFX 도메인을 조사했다.
제품 설명, 무료 범위, 라이선스 본문과 기술 정보를 직접 확인했다. 바이너리를 다운로드하지 않았고 Unity 임포트·렌더·성능 시험도 하지 않았다. 아래 적합도는 프로젝트 요구를 기준으로 한 제작 판단이며 실제 화면 검증 결과가 아니다.
상세 표와 근거 URL은 같은 폴더 external-research.json에 있다.
